# 실제 브라우저 검증 · 2026-09-07

Codex 인앱 브라우저, 실제 1280×720 화면, `npm run dev`의 4201 포트에서 검증했습니다. 게임 상태를 주입하거나 점수를 조작하지 않았습니다.

- 연습 시작 → 주전자/면/스프를 첫 냄비로 실제 드래그 → 조리 → 장갑 선택 → 냄비를 쟁반으로 드래그: `완벽해요! +1,000원`과 매출 1,000원을 확인했습니다.
- 별도 키보드 조리 `W 1 / N 1 / S 1 / M 1 / Enter`에서도 서빙과 매출 반영을 확인했습니다.
- 일시정지 → 계속 끓이기, 요리법 → 알겠어요 복귀를 확인했습니다.
- 첫 검수에서 아래 냄비와 쟁반이 화면 밖으로 잘렸습니다. 높이 기반 크기 조정 후 네 냄비·주전자·장갑·서빙 쟁반이 720px 화면 안에 함께 보입니다.
- 개발자 콘솔 경고/오류 기록은 비어 있었습니다.
- `preview.jpg`는 위 실제 플레이에서 매출 1,000원이 표시된 화면입니다. CPU 렌더는 `previews/kitchen-cpu.png`로 별도 구분합니다.

모바일 크기 변경을 요청했지만 도구의 실제 viewport는 1280×720을 유지해 모바일 통과로 기록하지 않습니다. 실제 휴대전화 터치, 오디오 청취, 브라우저에서 3일 연속 완주는 미검증입니다. 3일 완주와 실패 분기는 일반 입력을 사용하는 CPU 테스트로 별도 검사합니다.
