# 검증 기록

2026-09-07, Node.js 24.15.0. 아래는 작업 에이전트가 직접 완료한 **CPU/빌드** 검사이며 실제 브라우저 결과와 구분한다.

- `npm ci`: 깨끗한 잠금파일 설치 성공. 선택적 macOS 파일감시 `fsevents`의 설치 스크립트 미승인 경고는 있으나 설치/테스트/빌드에 실패하지 않았으며 따로 스크립트를 승인하지 않았다.
- `npm test`: 정상 입력으로 3일 완주, 모든 냄비 조리/주문·팁·실패, 일시정지, 모든 히트박스, 렌더 순수성, 드래그/물 붓기/자산 누락 폴백을 검사한다.
- `npm run build`: 일반 Vite 정적 빌드 성공.
- `npm audit`: 알려진 취약점 0개(당시 잠금파일).
- `npm run capture`: 생성 배경과 실제 조리 상태를 CPU Canvas에서 합성한 `docs/previews/kitchen-cpu.png`. 브라우저가 아니며 시각 프리뷰로만 사용한다.
- unslop-ui 고위험 스캐너: 검사 대상 소스 7개, finding 0. 이는 색/폰트/템플릿 신호 검사이며 게임 재미/시각 품질 점수는 아니다.

CPU WOFF2 로더의 폰트 등록 실패를 발견하여 CPU 캡처/테스트에만 공식 `galmuri@2.40.3` TTF를 사용했다. 런타임은 동봉 WOFF2를 사용한다. 로컬 OS 폰트를 복사하지 않았다.

실제 브라우저 검증은 통합 담당자가 별도 수행 중이다. 이 파일의 CPU 결과는 키보드/마우스/터치 브라우저 검증, 모바일 실기기, 오디오 청취 또는 사람의 캠페인 완주를 증명하지 않는다.
